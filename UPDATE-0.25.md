# 0.25.1 — Regimental orders and direct launch

Division orders go to regiment command groups; their battalions execute delegated missions. Main effort affects supply priority. The regular division scenario lists the 8th, 12th and 22nd Infantry; Beach Exits lists only the 8th. Original unit IDs and boundaries are preserved.

A visible Full screen button requests browser full-screen mode when supported. A browser or embedded viewer may deny it. On iPad, launch the direct GitHub Pages address from Safari or add it to the Home Screen as a web app. No website can force another app to hand a link to Safari.

Physical HQ/radio range mechanics remain the legacy model. Regimental orders are a tested order/delegation layer, not a claim of the complete planned HQ refactor.

Validation: regimental engine/UI and save/exit checks, frontage, division setup, offline shell, command desk, AI, reinforcement and visibility regressions; browser test of separate orders to all three regiments and turn resolution. iPad acceptance pending.
