# Utah Command — 0.26.1

Free independent WWII operational command game. Game design and development lead: Larry Kuzniak. Development assistance: OpenAI ChatGPT/Codex.

Play: https://larrykuzniak.github.io/Utah-Command-/game/start-0261.html

You command the 4th Infantry Division. Division orders go to the 8th, 12th and 22nd Infantry Regiments; Regimental orders go to their own battalions. Each regiment has its own HQ and distribution status. Smaller scenarios are marked regimental exercises.

0.26.1 fixes overlapping sticky controls, the empty supply column and stretched air-support card. Battle rules and saved games are unchanged from 0.26.0. See UPDATE-0.26.md for the command model and UPDATE-0.26.1.md for the layout repair.

Current editable source: game/. Run node build-current.cjs after edits. Generated assets must match the current source. Previous builds are archived outside the active game files. Old launch entries serve current HTML; offline navigation maps historical launch entries to the current cached index.

On iPad, open the direct address in Safari and add it to the Home Screen with Open as Web App. Export/Import transfers battles between hosts or devices. Browser checks passed; real iPad acceptance is pending.
